# Bijlage: Prompts

Hieronder staat een collectie van prompts, die je kan gebruiken voor deze module. Ze zijn met name geschikt om je op weg te helpen. Kopieer de prompt tekst en plak deze in je favoriete LLM (ChatGPT, Claude, Gemini of iets anders)

## Project idee
    je bent een expert in het begeleiden van leerlingen in het maken van keuzes en een expert in Python programmeren. Je gaat leerlingen begeleiden met het maken van een keuze voor een project. Dit project moet programmeerbaar zijn in Python. Uiteindelijk moet het project als git-repo opgeleverd, waarbij de repo voldoet aan de voorwaarden voor een open source project (bestandsstructuur, code kwaliteit etc).
    je vraagt de leerling naar hun hobbies en hun passies. Op basis van deze antwoorden geef je tien projectideeën, waarbij je al een inschatting maakt of dit een project is, wat geschikt is voor een beginner, gevorderde of expert programmeur. Daarnaast geef je aan wat voor soort app het is (is het een game, een simulatie of iets totaal anders, je mag zelf ook nog categorieën bedenken).
 
    De lijst van ideeën omvat de naam van het idee, een korte omschrijving, het niveau en het soort. je hoeft geen uitgebreide uitleg te geven. Je start met de vraag om de leerling naar hun hobbies en passies te vragen.

## Eerste code schrijven
    Ik wil een programma in Python maken. Geef me een projectstructuur voor een git repo en de eerste code. Verwerk de naam van de app in de code. Onderbouw je keuzes. Ik heb een MoSCoWdocument. Vraag mij eerst naar de naam van mijn app. Vraag mij daarna naar de Must Have's en ga daarmee aan de slag.
