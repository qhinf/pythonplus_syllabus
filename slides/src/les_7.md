## Testen op een andere computer

1. Download je repo via GitHub (of `git clone`)
2. Maak een nieuwe virtual environment aan
3. Installeer packages: `pip install -r requirements.txt`
4. Start je programma: `python main.py`

---

## Als het niet werkt...

- Controleer je `requirements.txt`
- Controleer je pad-verwijzingen (gebruik relatieve paden!)
- Vraag om hulp 🙋
